# Fluxo RH

Landing page oficial da **Fluxo RH**, consultoria de carreira voltada a profissionais em recolocação, transição ou fortalecimento de posicionamento profissional.

## Estrutura

- `index.html` — página principal
- `css/styles.css` — identidade visual e responsividade
- `js/main.js` — menu mobile, interações e formulário para WhatsApp
- `assets/fluxo-bg.svg` — arte abstrata inspirada na identidade visual da marca
- `assets/logo-fluxo.svg` — assinatura vetorial auxiliar

## Publicação

O projeto foi estruturado para funcionar diretamente no **GitHub Pages**, sem backend.

O formulário de contato monta uma mensagem personalizada e abre o WhatsApp para revisão antes do envio.

## Identidade

A V2 preserva o DNA colorido da Fluxo RH, mas usa uma base predominantemente clara, mais espaço em branco, hierarquia visual mais forte e uma jornada B2C orientada ao momento profissional do visitante.
